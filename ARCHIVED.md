# Archived project notice

WMDiscord is archived and is no longer actively maintained by the original author.

The code is preserved for reference, experimentation, and independent continuation. Forks are welcome under the terms of the GPL-2.0-only license.

The final source snapshot is experimental and incomplete. The 0.3.1 application compiled on the original test system, but its demo window was not observed appearing in the reported Window Maker test. A 0.3.2 follow-up source snapshot was prepared, but its end-to-end behavior was not verified. Earlier RPC testing did authenticate and retrieve a voice-channel snapshot, but the full overlay experience was not validated end-to-end.

There is no promise of support, security updates, compatibility fixes, or future releases. Fork maintainers should review the code, Discord's current developer policies, and the security notes before using it.
